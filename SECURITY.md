# Security Policy

## Authorized scanning only

WpBuddy is a security assessment tool for WordPress sites. Running it
against a website is active reconnaissance: even the passive phase sends
requests, and the opt-in phases (`--access`, `--dict`, `--enum-plugins`,
`--verify-pocs`) exercise login endpoints and reach component code.

**Only scan assets you own or have written authorization to test.**
Unauthorized scanning is illegal in most jurisdictions. The tool prints
this disclaimer on every run and it applies to every use of the code.

## Reporting a vulnerability in WpBuddy itself

- Open a GitHub issue with reproduction steps for the vulnerable code
  path, or email the maintainers if the finding is sensitive.
- Do NOT test exploits against systems you do not own.
- We aim to respond within 7 days and to fix confirmed issues in the
  next patch release.

## Disclosure of scan findings

Reports generated by WpBuddy (`outputScan*.md`, `wpbuddy-audit/`,
`*.json` knowledge graphs) may contain credentials and secrets found on
the scanned site. Treat every artifact as sensitive: do not commit them
(the repository's .gitignore excludes them) and share them only over
encrypted channels with the asset owner.
